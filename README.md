# Hallmark Web Design for Manus

A Manus skill for distinctive, evidence-led web design and redesign that avoids generic AI-generated UI.

This is an independent workflow adaptation inspired by [Hallmark](https://github.com/nutlope/hallmark) by Nutlope/Together AI. It preserves the useful design method and anti-pattern checks while keeping the skill concise, Manus-compatible, and adaptable to existing products.

## Use it for

- substantial website redesigns;
- distinctive landing pages and app surfaces;
- responsive UI critique and implementation planning;
- content-led products that need a real visual identity;
- audits against generic AI-generated interface patterns.

## Install as a Manus skill

Use the packaged `.skill` file or copy the `SKILL.md` directory into your Manus user skills. The main skill is intentionally small; detailed gates and SMARTBALL AI guidance live in `references/`.
